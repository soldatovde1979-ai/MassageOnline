## Ключевые решения и почему

- **По делегированию** (ревью §7):
  - В-1 (б) — ТЗ считается исходным документом;
  - В-4 (а) — **один бот** `MariaMassage_bot` на всё;
  - В-5 (а) — бот и вебхук относятся к этапу 14, Mini App и напоминания — к этапу 13;
  - В-6 (а) — вернуть запись можно **30 минут с момента отмены**, в любом канале;
  - В-7 (а) — бот не называет цены;
  - В-10 (б) — факты о коде берём из knowledge, переписки и эмулятора.
- **Клиентская витрина — статический сайт на GitHub Pages (0 ₽), Apps Script — только API.** Запросы идут через `doPost` с JSON в `text/plain`, без preflight. Решение принято в этом заходе по делегированию и **в ревью и my-FT пока не внесено**.
  - Почему: у страниц Apps Script на личном аккаунте сверху плашка «создано пользователем Apps Script». Страница живёт в iframe, отсюда масштаб «как сайт» — замечание №8. В Mini App недоступен `initData`, и нет установки на экран телефона.
  - Старая GAS-страница остаётся запасным входом.
  - Пункты ревью 3.1 и 3.10 и этап 13 плана написаны под GAS-страницу — их нужно переписать.
- **Новые API кладём в файлы `52_*`**: GAS грузит файлы по имени, и `ROUTES` в `53_Router.gs` ссылается на функции при загрузке.
- **Отвергнуто:**
  - ИИ-беседа в форме записи (24.08) — снижает конверсию;
  - `initData` внутри GAS-iframe;
  - вложенные папки в `src/`;
  - тесты внутри `src/`;
  - слияние «буфер обязан влезть в окно» — отменено ради последнего сеанса дня.
