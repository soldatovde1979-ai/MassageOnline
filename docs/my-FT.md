**Обозначения**

| Знак | Смысл |
|---|---|
| **Т-N** | требование |
| `[ ]` | не выполнено или не принято (код без приёмки — тоже `[ ]` с пометкой `> K:`) |
| `[x]` | выполнено и принято |
| ⏳ | предложение ИИ; в работу не берётся до подтверждения |
| **В-N** | вопрос: контекст, варианты с последствиями, «Ответ: ждём» |
| ❓ / ✅ | вопрос открыт / закрыт (ответ словами пользователя + «→ применено: …»); вопрос не удаляется |
| **Р-N** | решение пользователя |
| Чулан | чего ИИ не знает, не понял или что противоречиво; созревший пункт становится вопросом |
| `> K:` | пометка ИИ, не длиннее двух строк; детали — в `spec.md` / `data.md` |

**Порядок**
- **Стоп-правило:** пока в разделе есть ❓ или ⏳, код и постановка по нему не пишутся.
- Номера Т-, В-, Р- не переиспользуются и не перенумеровываются.
